# A04 – Fallos Criptográficos: Soluciones

## Reto 1 – Hashes MD5 sin sal
`/a04/hashes` expone los `password_hash` de todos los usuarios. MD5 sin sal se rompe en
segundos con tablas arcoíris o fuerza bruta (crackstation.net, hashcat).

**Corrección:** usar `bcrypt`, `scrypt` o `argon2` con sal única por usuario y un costo
computacional ajustable.
```js
const bcrypt = require('bcrypt');
const hash = await bcrypt.hash(password, 12);
const ok = await bcrypt.compare(password, storedHash);
```

## Reto 2 – Base64 como "cifrado"
`/a04/store` codifica y decodifica en base64, que es reversible por cualquiera sin llave.

**Corrección:** usar cifrado simétrico autenticado real (`crypto.createCipheriv` con
AES-256-GCM) y una llave gestionada por un KMS, nunca hardcodeada.

## Reto 3 – Token predecible
El token de sesión es `MD5(username + "static_salt_2024")`, calculable sin iniciar sesión.

**Corrección:** generar tokens con `crypto.randomBytes(32)`, almacenarlos server-side (o
firmarlos con JWT + secreto robusto) y nunca derivarlos de datos públicos.
