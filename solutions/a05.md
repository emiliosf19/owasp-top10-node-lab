# A05 – Inyección: Soluciones

## Reto 1 – Bypass de autenticación por SQLi
Usuario `admin`, contraseña `' OR '1'='1` en `/a05/login` inicia sesión sin conocer la
contraseña real, porque el SQL se arma por concatenación de strings.

**Corrección:** usar siempre consultas parametrizadas.
```js
const user = db.prepare('SELECT * FROM a05_users WHERE username = ? AND password = ?')
  .get(username, password);
```

## Reto 2 – Extracción de datos con UNION
En `/a05/search`, `' UNION SELECT id,username,password,role FROM a05_users--` filtra la
tabla de usuarios completa a través del buscador de productos.

**Corrección:** parametrizar la consulta y validar el tipo/longitud del término de
búsqueda; nunca interpolar entrada de usuario en el texto SQL.

## Reto 3 – Inyección de comandos del sistema
En `/a05/ping`, `127.0.0.1; id` ejecuta un segundo comando arbitrario porque `exec()`
invoca una shell.

**Corrección:** usar `execFile('ping', ['-c', '2', host])` (sin shell) y validar `host`
contra un patrón estricto de IP/hostname antes de usarlo.
