# A01 – Control de Acceso Roto: Soluciones

## Reto 1 – IDOR en el perfil
Inicia sesión como `alice` (sin contraseña) y navega manualmente a:
- `/a01/profile/2` → datos de Bob, incluida su identificación nacional
- `/a01/profile/3` → identificación nacional del admin

**Por qué funciona:** la ruta `profile/:userId` obtiene cualquier ID sin verificar que
`session.a01User.id === userId`.

**Corrección:**
```js
function profile(req, res) {
  const userId = Number(req.params.userId);
  const current = req.session.a01User;
  if (!current || (current.id !== userId && current.role !== 'admin')) {
    return res.status(403).send('Prohibido');
  }
  // ...
}
```

## Reto 2 – Panel de administración sin verificación de rol
Estando como `alice` (rol=user), navega a `/a01/admin`.
El panel muestra todos los usuarios porque no existe una verificación de `role === 'admin'`.

**Corrección:**
```js
function admin(req, res) {
  const user = req.session.a01User;
  if (!user || user.role !== 'admin') return res.status(403).send('Prohibido');
  // ...
}
```

## Reto 3 – IDOR en pedidos
El pedido de Alice es el #1. Navega a `/a01/orders/2` o `/a01/orders/3`.

**Corrección:** verifica que `order.user_id === session.a01User.id` (o que el rol sea admin)
antes de devolver el registro.
